### Como criar anexar e postar um GitHub 
Para criar um repositório no GitHub assim que criar a conta no lado superior direito estará um bloquinho escrito "novo repositório", é sempre bom deixar público o repositório para que as pessoas consigam ver o que você anda fazendo, ative o modo REDME para que você consiga escrever textos no arquivo.
Assim que criei o repositório abri o terminal e achei a pasta que queria vincular e arrastei o arquivo para a parte demarcada do repositório do GitHub e ela foi anexada, salvei e enviei.
Resumindo tudo criei o repositório no GitHub, conectei a o arquivo que queria salvei e postei na minha página do GitHub
